Password Credential Test

A small, local-only page for trying the browser Credential Management API with a PasswordCredential.

Use test-only values. Clicking “Store” may save the entered password in this browser’s password manager for this site. This page makes no network requests and never prints the password to the log. A web page cannot delete a saved password credential; remove it in the browser’s password manager if needed.
